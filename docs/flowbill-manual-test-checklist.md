# FlowBill 実機確認チェックリスト

**用途:** 品質保証フェーズの手動確認  
**作成日:** 2026-07-26  
**前提:** Supabase モード・ログイン可能・書込権限（member 以上）で実施  
**記入:** `[ ]` → 実施後 `[x]`。該当なしは `N/A`、未実施は空欄のまま。

関連: `docs/flowbill-quality-roadmap.md` / `docs/flowbill-test-matrix.md`

---

## 使い方

1. 環境（本番 / ステージング / ローカル）と日時・実施者を記録する
2. 各領域を上から実施し、列ごとにチェックする
3. 失敗時は「結果メモ」に症状・再現手順・スクショ有無を書く
4. **再読み込み** = ブラウザのハードリロード（またはフルリロード）
5. **ログアウト → 再ログイン** = セッション再取得後もデータが残ることの確認
6. **モバイル** = 実機または DevTools で幅 ≤ 390px 相当

| ブラウザ / OS | |
| アカウント権限 | owner / admin / member / viewer |
| 備考（適用済み SQL 等） | |

### 判定記号

| 記号 | 意味 |
|------|------|
| `[x]` | PASS |
| `[ ]` | 未実施 |
| `FAIL` | 失敗（メモ必須） |
| `N/A` | 機能なし / 対象外 |
| `BLOCKED` | 権限・データ不足で実施不可 |

## 凡例（列の意味）

| 列 | 確認内容 |
|----|----------|
| 新規 | 新規作成ができ、一覧・詳細に出る |
| 編集 | 編集画面で変更できる |
| 削除 | 削除（または論理削除・終了）が仕様どおり |
| 保存 | 保存成功が分かり、内容が永続化する |
| 再読み込み | リロード後も内容・件数が同じ |
| ログアウト | ログアウト後に業務データが見えない / ログイン画面へ |
| 再ログイン | 再ログイン後も内容が復元される |
| PDF | PDF 保存（または「PDFを保存」導線）が使える |
| 印刷 | 印刷プレビュー / 印刷が使える |
| モバイル | 主要操作がモバイル幅で破綻しない |
